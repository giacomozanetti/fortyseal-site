Sicurezza e crittografia

I computer quantistici, quando abbastanza potenti, potranno rompere RSA ed ECC. La crittografia post-quantistica usa algoritmi immuni a questo attacco. FortySeal usa ML-KEM-1024 e ML-DSA-87 — standard NIST dal 2024, dopo 8 anni di selezione internazionale.

Gateway enterprise

Il PQC Storage Gateway è un layer crittografico che si interpone tra le tue app e qualsiasi storage S3-compatible. Ogni file viene cifrato prima di raggiungere il cloud — il provider riceve solo dati illeggibili.

Amazon S3, MinIO, Cubbit DS3, Wasabi e Backblaze B2. Stesso endpoint REST, stesse chiamate — il Gateway cifra in trasparenza prima dell'upload.
